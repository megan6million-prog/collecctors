# Betpawa HTFT Bot

Places 1 UGX bets on all +EV HTFT markets for English League matches.

## Env vars
- `BP_PHONE` — betpawa phone (default: 0705949189)
- `BP_PIN`   — betpawa PIN (default: 4413)
- `STAKE_UGX` — stake per bet in UGX (default: 1)
- `DRY_RUN`  — true/false (default: true)
- `LOG_FILE` — path to bet log

## Matrix
380 English League pairs, 1109 signals, avg EV +141%
